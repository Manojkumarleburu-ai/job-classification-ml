# Job Classification Using Machine Learning Algorithms

## Project Overview
This B.Tech project uses machine learning algorithms to classify jobs based on job-related attributes. It includes an interactive web application built with Streamlit.

## Features
- Explore the dataset and its summary
- Select different machine learning algorithms
- View model accuracy
- Predict job classifications using input attributes

## Technologies Used
- **Programming Language:** Python 3.11
- **IDE:** PyCharm
- **Web Application:** Streamlit
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn

## Dataset
The project uses `jobclassinfo2.csv` for model training and evaluation.

## How to Run

1. Install Python 3.11.
2. Install the required libraries:

   ```bash
   python -m pip install streamlit pandas numpy scikit-learn
   ```

3. Start the application:

   ```bash
   python -m streamlit run code.py
   ```

4. Open the local URL displayed in your terminal.

## Project Files
- `main.py` — machine learning implementation
- `code.py` — Streamlit application
- `jobclassinfo2.csv` — project dataset
- `FINAL_DOCUMENTATION_BATCH_20.pdf` — project documentation

## Disclaimer
This repository contains an academic project. Model performance depends on the dataset and evaluation methodology.
